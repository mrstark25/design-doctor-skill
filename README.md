# Design Doctor

A downloadable **Claude Code skill** that audits and redesigns websites and landing pages so they
look **made by a senior designer — not generated by AI.** It can walk existing code or fetch a live
URL, commit to a real visual direction, rebuild with depth/motion/craft, serve it, and verify it.

Built and hardened across a real redesign project. Encodes the lessons the hard way:

- **An anti-AI checklist** — bans aurora blobs, gradient headline text, glowing glass cards,
  rainbow chips, system-sans-only, and the rest of the generative-UI fingerprint.
- **Never hide content behind JS** — no scroll-reveal that leaves the page blank until you scroll.
  Content is visible by default; motion is pure-CSS-on-load and additive only.
- **Serve-and-verify discipline** — relative asset paths (works via `file://` and a server),
  cache-busting, `node --check` + CSS validation, curl for HTTP 200.
- **Proven reference code** — a reusable editorial-Swiss CSS system, component recipes (live data
  tables, swap panels, routing diagrams, count-ups), and a starter template.

## What's inside

```
skills/design-doctor/
  SKILL.md            orchestrator: fetch/read → diagnose → direction → rebuild → serve → verify
  ANTI-AI.md          banned patterns + required qualities (the core file)
  DIRECTIONS.md       committed visual directions (editorial-Swiss spec + alternatives)
  WORKFLOW.md         step-by-step, incl. the no-hidden-content rule + serving/caching
  RUBRIC.md           10-point scoring, bands, auto-fail conditions, definition of done
  reference/
    editorial-swiss.css   reusable primitives (set --H to your brand hue)
    patterns.md           copy-adaptable recipes for signature components
    starter.html          minimal page wired to the reference CSS
agents/
  design-auditor.md   read-only reviewer that scores surfaces + flags AI tells / blank-on-load
```

## Install

```bash
./install.sh
```

This copies the skill into `~/.claude/skills/design-doctor` and the agent into
`~/.claude/agents/design-auditor.md`. Set `CLAUDE_HOME` to install elsewhere. Restart Claude Code
(or start a new session) so it picks them up.

## Use

In Claude Code:

- `/design-doctor` — then describe the page or paste a URL
- "use design-doctor to redesign https://example.com/landing"
- "audit my landing page and upgrade it — don't make it look AI-generated"

The skill will diagnose, propose a direction, rebuild surface-by-surface, serve it locally, and
tell you exactly how it verified the result. It keeps a `.bak` of bold rewrites so you can compare.

## Requirements

- Claude Code (skills + subagents support)
- For serving previews: `python3` (or any static server). Internet for the web fonts.
